WhatsApp Cloud API: what a bot can send

A visual guide to every message type our bot can use through the same POST /{PHONE_NUMBER_ID}/messages endpoint we already call. The mockups show roughly how each one appears on the user's phone. Each card lists the limits, the webhook reply we receive, and an idea for the sticker vault.

Image, video, audio, document easy

  • image: JPEG/PNG up to 5 MB
  • video: MP4/3GP up to 16 MB
  • audio: AAC/MP3/OGG up to 16 MB. OGG Opus is shown as a voice note.
  • document: any file up to 100 MB, with a filename
{ "type": "image", "image": { "link": "https://…/collage.png", "caption": "Weekly collage" } }
💡 Sticker idea: an "export" command that sends a ZIP of every sticker as a document, or a collage image of the top stickers.

Reply buttons easy

  • Up to 3 buttons. Each title is at most 20 characters, and each id at most 256.
  • Optional header (text, image, video or document), a body of up to 1024 characters, and a footer of up to 60.
  • Tapping a button sends its title as a reply bubble, and the webhook receives its ID.
{ "type": "interactive", "interactive": {
  "type": "button",
  "header": { "type": "text", "text": "Sticker saved ✅" },
  "body":   { "text": "Tags: none yet. What next?" },
  "footer": { "text": "Sticker Vault" },
  "action": { "buttons": [
    { "type": "reply", "reply": { "id": "tag:abc123",  "title": "🏷 Add tags" } },
    { "type": "reply", "reply": { "id": "random",      "title": "🎲 Random sticker" } },
    { "type": "reply", "reply": { "id": "del:abc123",  "title": "🗑 Delete" } } ] } } }

// webhook →
{ "type": "interactive", "interactive": { "type": "button_reply",
  "button_reply": { "id": "random", "title": "🎲 Random sticker" } } }
💡 Sticker idea: attach these buttons after every save or search result, so users no longer need to type commands like "delete" or "tag".

List message (single select) easy

  • One button opens a bottom sheet with up to 10 rows in total, split across up to 10 sections.
  • Each row has a title (at most 24 characters), an optional description (at most 72) and an id. The button label is at most 20 characters.
  • The user can pick only one row. For multi-select, see Flows below.
{ "type": "interactive", "interactive": {
  "type": "list",
  "header": { "type": "text", "text": "Found 7 stickers" },
  "body": { "text": "Pick one to send 👇" },
  "action": { "button": "Choose sticker", "sections": [
    { "title": "Exact match", "rows": [
      { "id": "send:abc", "title": "Grumpy cat", "description": "tags: cat, angry · used 12×" } ] } ] } } }

// webhook →
{ "interactive": { "type": "list_reply", "list_reply": { "id": "send:abc", "title": "Grumpy cat" } } }
💡 Sticker idea: when a search returns several matches, show a list instead of sending every sticker. A "Send all" row could keep the current behaviour.

CTA URL button easy

A message with one button that opens a URL. This keeps long links out of the chat. The button label is at most 20 characters, and the message can have a header and footer.

{ "type": "interactive", "interactive": {
  "type": "cta_url",
  "body": { "text": "Browse the whole vault…" },
  "action": { "name": "cta_url",
    "parameters": { "display_text": "Open vault", "url": "https://mmps…/stickers" } } } }
💡 Sticker idea: link to a small web gallery of the vault, like the Mindloop and Savings mini-apps.

Quote reply (context) easy

Add context.message_id to any outgoing message and it appears as a reply to that message. This is useful when the user sends several searches in a row.

{ "context": { "message_id": "wamid.HBg…" }, "type": "text", "text": { "body": "Found 3…" } }
💡 Sticker idea: quote the user's search word above its results, so concurrent searches don't get mixed up. It's also useful for "no match" replies.

Read receipt + typing indicator easy

Marks the user's message as read (blue ticks) and shows "typing…" for up to about 25 seconds, or until we reply. Both are done with one call.

POST /{PHONE_NUMBER_ID}/messages
{ "messaging_product": "whatsapp", "status": "read",
  "message_id": "wamid.HBg…", "typing_indicator": { "type": "text" } }
💡 Sticker idea: send this as soon as a message arrives, before downloading or resizing a sticker. That can take a few seconds.

Location message + location request easy

Flows more setup

  • Build the screens in WhatsApp Manager → Flows using JSON, then publish to get a flow_id.
  • Components: CheckboxGroup (multi-select), RadioButtonsGroup, Dropdown, TextInput, TextArea, DatePicker, OptIn, Image and text blocks. Flows can have several screens.
  • Static flows need no server. Dynamic flows (for example, checkbox options loaded from our DB) need an HTTPS data endpoint that uses RSA/AES encryption.
  • The result arrives in the webhook as interactive.nfm_reply.response_json.
{ "type": "interactive", "interactive": {
  "type": "flow",
  "body": { "text": "Tag your new sticker 🏷" },
  "action": { "name": "flow", "parameters": {
    "flow_message_version": "3", "flow_id": "<FLOW_ID>",
    "flow_cta": "Open tag editor", "flow_token": "sticker:abc123",
    "flow_action": "navigate",
    "flow_action_payload": { "screen": "TAGS" } } } } }

// webhook →
{ "interactive": { "type": "nfm_reply", "nfm_reply": {
  "response_json": "{\"tags\":[\"funny\",\"frog\"],\"flow_token\":\"sticker:abc123\"}" } } }
💡 Sticker idea: replace the 5-minute "next message is tags" window with a tag editor. Popular tags appear as checkboxes, with a free-text field for new ones. This removes the ambiguity between searching and tagging that we discussed.

Templates needs approval

  • These are the only messages the bot can start itself, or send more than 24 hours after the user's last message.
  • Create them in WhatsApp Manager. Meta reviews them, usually within minutes to hours. Categories are Marketing, Utility and Authentication, and each is priced differently.
  • They can have variables ({{1}}), a media header, quick-reply buttons and URL or phone buttons.
{ "type": "template", "template": { "name": "weekly_stats", "language": { "code": "en" },
  "components": [ { "type": "body", "parameters": [ { "type": "text", "text": "14" } ] } ] } }
💡 Sticker idea: a weekly digest or "new stickers were added to the shared vault" notification. This only works with an approved template.
