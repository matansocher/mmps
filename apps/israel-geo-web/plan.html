Product plan · Updated 2026-07-14

Israel Geo

A five-round Street View game for Israel. Players inspect a fixed panorama, draw a confidence circle, and balance precision against risk for up to 25,000 points.

Current state

Game

Complete game loop

Five rounds, fixed panoramas, confidence-circle scoring, hit/miss results, MongoDB records, and progressive location loading.

Location engine

Working

Generates one inhabited location immediately and preloads the next round while the player explores.

Engagement

Personal progression suite

Passport, rewards, Daily Route, City Crowns, Navigator XP, monthly Light Up progress, profiles, and private sharing are implemented.

Platform

Telegram + MongoDB

Production uses signed Telegram Mini App identity. Local development uses a fallback navigator and can run without configuring or starting the Telegram bot.

Current engagement release

Implemented

Israel Passport + Confidence Circles + Share Card

Every guess now includes a 1-150 km confidence radius. Small successful circles earn the highest score; misses take an immediate penalty and then decay based on distance beyond the edge. Passport stamps persist in MongoDB, and the final result can be shared as a spoiler-free image.

  1. Done - Israel Passport: first successful hit in each locality unlocks a stamp; later tighter hits improve its best-radius record.
  2. Done - Confidence Circle: tap a center, adjust a large radius slider, preview the maximum score, then lock the circle.
  3. Done - Share Card: generate a PNG with total score, five hit/miss results, radii, points, and new-stamp count without revealing locations.
  4. Done - Rewards Economy: earn Compass Coins, buy and equip twelve cosmetics, preview a weekly feature, and unlock Passport-exclusive items.
  5. Done - Server authority: Telegram-authenticated MongoDB profiles now own rewards, Passport stamps, records, cosmetics, XP, Crowns, streaks, and monthly progress.

Implemented progression release

Telegram-authenticated personal progression

Israel Geo is now a dedicated Telegram Mini App. Every player progresses independently, with no leaderboards, divisions, public search, duels, or player-comparison screens.

01 · AUTH

Dedicated Telegram bot

A new Israel Geo bot launches the Mini App. The server validates Telegram init data, uses MY_USER_ID during local development, and stores the player by Telegram user ID.

Required foundationMongoDB
02 · RETURN

The Daily Route

The same five locations are available to every player from midnight Israel time. Each player gets one rewarded attempt, then unlimited reward-free practice replays. Track current and best personal streaks.

No rankingsDaily return
03 · MASTERY

City Crowns

Each of the 18 localities has permanent mastery. A successful circle earns 10 mastery plus 5/10/15 for radii within 30/15/5 km. Tiers unlock at Bronze 30, Silver 100, Gold 250, and Crown 500.

Personal masteryPermanent
04 · MONTHLY

Light Up Israel

A personal monthly map tracks the 18 Passport localities. One successful scored Daily Route circle lights that locality. Lighting all 18 before month-end unlocks the month’s exclusive cosmetic.

Personal goalMonthly cosmetic
05 · IDENTITY

Navigator Identity

A player can edit their display name, select a built-in illustrated avatar, earn increasingly expensive XP levels, unlock a title every five levels, equip cosmetics, and display badges, Passport stamps, Crowns, and monthly maps.

Editable profilePersonal XP
06 · SHARING

Private shareable profile

Profiles are private by default. Players explicitly create a public link containing progress but no Telegram identity. Regenerating the token invalidates the previous link.

Privacy firstRevocable link

Removed from scope: Weekly Divisions and Five Lives Expedition. There will be no leaderboards or player-versus-player progression.

Persistence and authority

Identity

Telegram user ID

The server validates signed Mini App init data against the dedicated bot token. Local development authenticates as MY_USER_ID.

MongoDB

One durable player profile

Passport, coins, inventory, equipment, XP, titles, Crowns, streaks, Daily Route attempts, monthly maps, records, display name, and avatar are persisted server-side.

Server authority

No client-awarded progression

Scores, rewards, XP, Crown mastery, Daily completion, and Light Up progress are calculated atomically with the submitted guess. The browser only renders returned results.

Rewards economy

Earn

Compass Coins

Implemented values: 25 per completed game, 5 per successful circle, 5/10/15 for hits with 30/15/5 km circles, and 10 per new Passport stamp.

Spend

Cosmetics only

Twelve shop items cover Passport designs, map themes, guess pins, and share-card frames. Prices are 100, 180, or 300 coins.

Return loop

Weekly feature

The permanent catalog keeps every item available. One game-visible cosmetic is 20% off each week and can be previewed for one game.

Mastery

Passport exclusives

Unique cosmetics unlock at 3, 6, 12, and 18 stamps. These rewards cannot be purchased with coins.

Fairness

No gameplay advantages

Coins cannot buy points, easier circles, hints, leaderboard position, or additional attempts. Progress remains skill-based.

Future engagement ideas

These ideas preserve the personal, skill-based direction. They do not introduce leaderboards, pay-to-win advantages, or player-versus-player pressure.

Learning loop

Memory Lane

Build a private review route from locations the player missed badly. Revisit them days later and show improvement in circle size and distance.

High learning valueMedium effort

Local Story Cards

After a reveal, show one concise fact about the locality, its landscape, architecture, food, or history. Completed cards form a personal discovery album.

EducationalContent needed

Long-term identityHigh effort

Rules for healthy engagement

  • Do not sell score advantages, easier circles, or extra rewarded Daily Route attempts.
  • Do not use paid loot boxes or chance-based cash rewards.
  • Missing a day resets the current streak but never removes earned rewards or mastery.
  • Reward skill, discovery, and consistency—not excessive session length.
  • Keep profiles private by default and allow players to invalidate old share links.
