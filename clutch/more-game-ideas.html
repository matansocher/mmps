The Rule of This Doc

We now have NBA 🏀, Champions League ⚽, World Cup 🌍 and Euros 🇪🇺. Every idea below relies only on data points that all four tournaments share, so a single build ships to every league at once — the user just picks a league (or an "All Sports" mix).

✅ Safe shared data (use freely)

  • Year / season
  • Champion & Runner-up
  • Every matchup: two teams + winner
  • The scoreline / series result string
  • The round each matchup belongs to
  • Team logos (real crests/flags)

⛔ NBA-only (avoid for cross-tournament)

  • Seed numbers (1–8)
  • Conference (East / West)

These don't exist for the football tournaments, so no cross-tournament mode should depend on them.

⚡ Tier 1 — Quick Wins

Small builds that reuse the Rapid-Fire loop / card UI. High replay value, low effort.

🏆Who Lifted It?
QUICK WIN
"It's 1994. Who was crowned?"

Show a year + league crest, then 4 team logos. Tap the champion. Instant right/wrong flash, streak counter, endless. The purest trivia hook — a 3-second dopamine loop.

How to play
Year appears → pick the champion from 4 logos → next. Speed bonus for fast taps.
Scoring
+1 per correct, streak multiplier, one wrong ends the run (or 3 lives).
Data used
championseasonother champions as decoys
Viral hook
"I named 18 champions in a row"shareable streak card
🥈Both Finalists
QUICK WIN
"Name BOTH teams that reached the 2008 final."

Harder than champion-only. Show the year; the user must pick both the winner and the runner-up (from a grid of logos), then optionally mark which one won for a bonus. Rewards deep knowledge.

How to play
Select 2 of 6 logos → confirm → optional "who won?" tap for bonus points.
Scoring
Good = both finalists right. Great = also picked the winner correctly.
Data used

🎯 Tier 2 — Medium

New interaction patterns, still a single reusable screen per mode.

🧭Path to Glory
MEDIUM
"Retrace the champion's run — every team they beat, in order."

Pick a year's champion. We reveal their knockout path round-by-round with the opponent hidden. The user guesses (or drag-orders) each team the champion defeated on the way to the title. A story-driven mode that makes each run feel legendary.

How to play
Round 1 → "who did they beat?" pick from options → advance up the rounds to the final.
Scoring
+1 per correct opponent; perfect-path bonus; optional "no hints" multiplier.
Data used
roundsmatchupswinner
Viral hook
"traced the whole run blind"

Depth varies by tournament (some football editions are Final-only) — the mode just uses however many rounds a season has, so it self-scales.

🎲Odd One Out
MEDIUM
"Three of these teams won a title in the 2010s. One never did. Spot the fake."

Show 4 team logos under a prompt (e.g. "champions of this era"). Three genuinely won a title in the chosen window; one is a plausible impostor. Fast, punchy, endlessly generatable from the champion list.

How to play
Tap the team that does NOT belong → reveal → next.
Scoring
Streak-based, speed bonus, 3 lives.
Data used
champion setseason window
Viral hook
"got fooled by the decoy"

"Who has MORE titles in our data — Real Madrid or AC Milan?"

The viral classic. Two teams (or two years) face off; the user picks which has more championships (or which final happened earlier). Correct answer stays on screen and the next challenger slides in — endless chain. Trivially derived by counting champions per team.

How to play
Left team stays, guess if the right team has higher/lower title count → chain forever.
Scoring
Endless streak; personal best; league or All-Sports pool.
Data used

MEDIUM
"The 1970 final: Brazil vs Italy. What was the score?"

Reuses the bracket's good / great scoring philosophy as a standalone rapid mode. Show any final (or big matchup); the user dials in the exact result. Right winner = good; exact scoreline = great. Pure skill expression.

How to play
See the matchup → set each team's score → submit. Works for NBA series results and football scorelines alike.
Scoring
Good = correct winner. Great = exact result string match.

🚀 Tier 3 — Ambitious

🗓️Daily Five
AMBITIOUS
"5 questions. Same for everyone, everywhere, today only."

The Wordle engine for Clutch. Every day a fixed, seeded set of 5 mixed questions (a "Who Lifted It", a "Guess the Year", a scoreline, etc.) — identical for all players. One attempt. Emoji-grid result to share (🟩🟩🟨⬛🟩). This is the single biggest lever for daily-return + organic sharing.

How to play
Open app → today's 5 → one shot each → shareable score card + global leaderboard.
Scoring
Out of 5 (or points); streak of consecutive days played; percentile vs everyone.
Data used
everything, seeded by date
Viral hook
Wordle-style emoji sharedaily streakfriend leaderboards

Scoring

🪜Last Team Standing

"One of these five won in 1985. Eliminate the four that didn't."

An elimination-survival twist on trivia. A year is set and a pool of candidate teams appears; each turn you knock out one team you think did NOT win. Survive by never eliminating the real champion — the pool shrinks until only the winner remains. Tension builds every tap.

How to play

Scoring

Data used

🧲 Round 3 — The Addiction Engine

This round is different. Instead of more minigames, it's the meta-layer that makes the whole app a daily habit — the streak + scarcity + social loop that turns "fun once" into "opens every morning" — plus three fresh formats proven to go viral in sports. Everything still works across NBA, Champions League, World Cup and Euros.

💡 The core insight: Every mode we have is replayable, which is fun — but replayable isn't addictive. Addiction comes from scarcity + streaks + a shared scoreboard (the Wordle / Immaculate Grid formula). The single highest-leverage thing to build next isn't another game — it's the daily ritual below.

🏆 The Flagship

📅Clutch Daily FLAGSHIP
"Today's 5 questions — the same for everyone. How many did you get?"

Think Wordle, but for sports trophies. Every day there are 5 questions, and everyone in the world gets the exact same ones. You get one try. Answer them, keep your daily streak alive, and share how you did. New questions drop every day — so there's always a reason to come back tomorrow.

Why it hooks
You can only play once a day, so skipping a day feels like missing out. The growing streak number ("Day 34 🔥") is what pulls people back every single morning.
Sharing
Your result shows as colored squares (✅ / ❌) without giving the answers away — so friends have to tap the link and play it themselves to see how they'd do.
Data used
a daily mix from all 4 tournaments
Viral hook
"34-day streak""I beat 88% of fans today"share card with no spoilers

Reuses the daily-question code we already have. Very little new data needed — the biggest payoff in the whole doc.

🕹️ Three new viral formats

🔲Clutch Grid
AMBITIOUS
"Immaculate Grid for trophies — fill all 9 cells."

A 3×3 grid of intersecting constraints — rows like Won it all / Lost the final / 1990s, columns like NBA / Champions League / Reached the final twice+. Fill each cell with a valid team + year. The single most viral format in sports right now (Immaculate Grid pulls millions of daily plays), and our normalized champion/runner-up data across four tournaments is exactly its shape.

How to play
Tap a cell → search a team+year that satisfies both constraints → 9 guesses, rarity score for uncommon answers.
Scoring
Fill count + rarity (uniqueness of your picks vs other players); one grid per day.
Data used
championrunnerUpseasontournament
Viral hook
"9/9, rarity 140"shareable grid image
🎯Guess in 6 (Champion Wordle)
MEDIUM
"Guess the secret champion team in 6 tries."

The game picks one secret trophy-winning team. You guess team names, and after each guess it tells you how close you are — is it the same sport? The same decade? Is the real answer from an earlier or later year? Use those clues to zero in and crack it within 6 guesses. It's Wordle, but the hidden answer is a champion.

How to play
Type a team → clues light up (same sport? same decade? earlier/later year?) → use them to guess again → solve within 6.
Scoring
The fewer guesses, the better. A fresh secret team each day, plus a practice mode to play as much as you like.
Data used
championseasontournament
Viral hook
"got it in 3!"familiar Wordle-style share grid
🪜Survivor Bracket
AMBITIOUS
"Keep answering right to stay in. Last fans standing win the week."

A contest everyone plays together each week. You keep answering questions round after round — but get one wrong and you're out. The goal is simple: survive as long as you can. Because everyone's playing the same event at the same time, it becomes something people show up for — and the players who last the longest top the board.

How to play
Join the weekly game → answer each round → one wrong answer ends your run → see how far you got compared to everyone else.
Scoring
How many rounds you survived, plus your final rank. Resets every week for a fresh shot.
Data used
questions from any modemixed pool
Viral hook
"survived to Round 9"a live event everyone joins at once

🔒 Retention scaffolding (wrap it around everything)

🧊 Streak Freeze

Earn a freeze per perfect week; it auto-saves a missed day. Duolingo's masterstroke — protecting the investment increases play instead of ragequitting.

🏆 Weekly Leagues

Sun–Sun buckets of ~30 players; top 5 promote, bottom 5 relegate. Pure framing over existing scores — no new content, huge DAU lift.

🔔 Comeback nudges

"Your 34-day streak ends in 2h 🔥" / "Today's Daily is spicy — 3 tournaments in 5 Qs." Re-engagement is where retention is won.

🎖️ Badge cabinet

Unlockables — Decade Master, Globe Trotter (all 4 tournaments in a day), Ice Cold (perfect Daily). Collection completion is its own loop.

Build order: ship Clutch Daily + streak + share card first (the addiction engine), then Clutch Grid (proven sports-viral), then Weekly Leagues + Streak Freeze as a retention multiplier over what already exists.

📈 The Virality Layer (shared by all modes)

🟩 Shareable result cards

Wordle-style emoji grids + a clean image card ("Clutch · Who Lifted It · 18 streak"). One-tap share to socials/WhatsApp.

🔥 Daily streaks

"Day 12 in a row." Loss aversion brings players back every single day.

🏅 Leaderboards

Global + friends. Per-league and All-Sports boards so everyone can top something.

⚔️ Challenge a friend

Same seed via link → rivalry + rematch loop = built-in invitations.

🧭 My Recommended Order

  1. Who Lifted It? — fastest to ship, immediately fun, validates the endless-card loop reused everywhere else.
  2. Higher or Lower — proven-addictive format, tiny data footprint.
  3. Daily Five — the retention + sharing engine; this is what makes Clutch spread.
  4. Then layer in Path to Glory, Guess the Year, and the Head-to-Head Duel.
