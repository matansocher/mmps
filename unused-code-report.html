Methodology

The analyzer resolves TypeScript path aliases and relative imports, starts at src/index.ts, every apps/*/src/main.tsx, and code entry points named in package.json, then traverses the module graph. It builds a symbol-level graph for named functions, arrow functions, methods, getters, and setters. A function passed as a callback counts as reachable. Test files and files under a scripts directory are analyzed independently.
